# AISHELL-3 辅助数据使用

AISHELL-3 提供中性普通话朗读音频、文字与拼音转录及说话人元数据，可以用来建立**说话执行耗时**参考，并评价独立翻译器探针的预测。它不是已经整理好的 LLM 指令训练集；本次先做离线统计与留出评测，没有接入正式翻译器、调用模型或微调。

数据来源与许可见 [OpenSLR 93](https://openslr.org/93/)：Apache 2.0。代码仓库计划采用 MIT，不改变数据自身的许可；原始数据和分析输出保持在 Git 之外。

## 运行

用户下载的文件位于 `/home/zyth/data_aishell3.tgz`。可先检查压缩流完整性，再运行分析：

```bash
gzip -t ~/data_aishell3.tgz
uv run --locked python scripts/analyze_aishell3.py \
  --archive ~/data_aishell3.tgz \
  --outdir sceneweave-runs/aishell3/demo
```

默认每人选 16 条训练录音、8 条测试录音，按 `seed/split/音频身份` 的 SHA256 排序选择；不足数量时全部选取。可用 `--train-per-speaker`、`--test-per-speaker`、`--seed` 修改抽样。每次使用新的输出目录，工具拒绝覆盖非空目录。

工具流式扫描整个压缩包，只读取入选 WAV 到内存，不全量解压，不更改原包。扫描过程输出进度。压缩包损坏、转录格式非法等错误会留下 `failed` 状态；缺配对或入选音频不符合处理条件标为 `complete_with_errors`，返回非零。只有成功扫到归档结束才输出完成状态。脚本的 tar 解析检查不能替代独立的 `gzip -t` 压缩流校验。

## 实际字段与计算口径

本次原包盘点得到 train 63,262 条、test 24,773 条，共 88,035 条音频。训练集 174 人、测试集 214 人，其中 170 人重叠，44 人只出现在测试集。原始 split 包含同人留出及未见说话人两种情形，报告分别评价，不能把整个 test 当作新角色测试。

归档的 `spk-info.txt` 包含说话人身份、年龄组、性别、口音。年龄组按文件原文记录，当前文件写的是 A:<14、B:14–25、C:26–40、D:>41；不从其他介绍覆写这些标注，也不推导年龄或性别对语速的因果关系。

`train/content.txt` 和 `test/content.txt` 的每行是音频文件名、文字 token 与拼音 token 交替排列。例如：

```text
SSB00010001.wav    今儿 jinr1 好 hao3
```

这条示例有 3 个文字字符、2 个发音标注单元。工具分别记录 `char_count` 和 `unit_count`，语速基线采用标注单元/秒；不能把它直接混称为严格的汉字/秒。转录格式中的拼音不会计入文字。

时长分两个口径：

- `file_duration_ms`：WAV 的帧数/采样率，含录音首尾留白。
- `estimated_trimmed_span_ms`：以 20ms 窗口、16bit PCM RMS 门限100（约−50dBFS）、40ms首尾保留量估计的跨度。只裁首尾，句中停顿保留。

固定振幅门限是启发式，低音量、噪声和软辅音会影响边界；裁剪跨度不是人工标注或语音识别 VAD 真值。全静音/低于门限等样本保留错误记录并排除出统计；两种口径的误差分别报告。

## 看哪些输出

| 文件 | 用途 |
| --- | --- |
| `report.md` | 语速分布、总体/个人参考基线、已见/未见说话人的误差、实际文本及耗时例子 |
| `samples.jsonl` | 每条入选样本的源路径、文本、拼音、元数据、测量、预测与错误，便于追溯 |
| `speaker_profiles.json` | 只由 train 产生的总体及各说话人语速中位数、p10、p90 |
| `summary.json` | 归档盘点、抽样数量及各组 MAE、MAPE、中位相对误差、±20%覆盖率 |
| `manifest.json` | 数据路径、大小、mtime、工具哈希、抽样与裁剪参数、实际元数据定义和状态 |

这些结果来自每人限量的分层抽样，不代表全量耗时统计或原始频率。经验 p10/p90 不是已经校准的预测置信区间。

## 接下来如何使用

先把训练参考用于独立的说话耗时对照：相同 `say` 动作文本，比较没有辅助信息、带允许使用的训练语速/例子的模型预测，以及本脚本的简单基线。把真实测试耗时留在评价端，不能送进模型输入，也不能从当前测试录音反算出语速再预测同一句。

已见说话人可比较个人训练语速的作用；未见说话人用总体训练语速回退。虚构角色与数据中的真实说话人没有天然对应关系，不应凭姓名、年龄、性别自动绑定一个人的语速。可在未来角色自己的参考片段足够时再建立个体口径。

如果辅助信息已经有效，再考虑把训练样本转换成结构化“文本、已知条件→执行时长”的微调数据；先保留独立评测集，避免把测试集用于调阈值或训练。这次没有实施这些模型实验。

语料主要是中性朗读，没有疲劳、紧张或争吵的对应标签，不能据此编造修正系数。它帮助估计 `expected_end - start`，不能给出行动开始延迟、打断、并发资源冲突或 World 的实际成功结果。
